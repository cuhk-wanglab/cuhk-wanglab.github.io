Wang Lab V4 — 根域名 GitHub Pages 上传包

适用网址：https://cuhk-wanglab.github.io/

请把本包解压后，将里面的所有文件和文件夹（包括 .nojekyll）上传到名为 cuhk-wanglab.github.io 的仓库根目录。不要再放进 homepage-v4/ 子文件夹。

在 GitHub 仓库 Settings > Pages 中选择 main 分支和 /(root)，提交上传内容并等待 Pages 部署完成。

本包已经将站内链接、图片和样式路径、canonical、sitemap 以及 robots.txt 中的地址从 /homepage-v4/ 改为根路径 /。
