Wang Lab V4 — GitHub Pages upload package

This package is configured for the public base URL /homepage-v4/. It includes Homepage V4, all eight internal pages, News activity photos, and the Fun photo archive (43 albums, 267 photos, plus the original birthday slideshow link).

For a repository named homepage-v4, upload every item in this folder to the repository root.
For the account site repository cuhk-wanglab.github.io, upload this folder's contents into a homepage-v4/ directory.

Enable GitHub Pages from the main branch and the repository root (or the homepage-v4 directory, if using a workflow that publishes a subdirectory).
